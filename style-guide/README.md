# style-guide/

Estilo del proyecto que los *builds* deben respetar. **Llénalo por proyecto** (o déjalo vacío y las skills te lo pedirán). Nada viene precargado: el template es agnóstico y no hornea marca.

- **`design-system.md`** — reglas visuales: colores, tipografía, espaciado, logo, do/don't.
- **`writing-style.md`** — reglas de escritura: tono, palabras/patrones a evitar, formato.
- **`assets/`** — logos, fuentes, imágenes.

Lo consumen las skills:
- `apply-design-system` — al construir UI / material visual.
- `apply-writing-style` — al redactar cualquier entregable de texto.

> Si tienes un export de **Claude Design**, puedes soltarlo en `assets/` (o instalarlo como skill) y apuntar `design-system.md` a él.
