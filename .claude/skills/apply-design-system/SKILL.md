# apply-design-system — Construir con el sistema de diseño

## Objetivo
Que todo lo visual que se construya use el sistema de diseño del proyecto, no una marca inventada.

## Procedimiento
1. **Carga el sistema de diseño:** lee `style-guide/design-system.md` y revisa `style-guide/assets/`.
2. **Si está vacío o es el placeholder:** pregúntale al usuario lo esencial (colores, tipografía, logo) o si prefiere soltar un export de Claude Design. **No inventes marca.**
3. **Aplica los tokens:** usa exactamente los colores, tipografía, espaciado y assets definidos; respeta el do/don't.
4. **Construye** el artefacto/UI con eso.
5. **Revisa** que el resultado sea fiel al sistema antes de entregar.

## Principios
- **Nunca inventes** colores, tipografía ni logo: usa lo definido o pregunta.
- Un sistema de diseño incompleto se completa **preguntando**, no adivinando.
- **Reusa `assets/`** en vez de recrear logos.
