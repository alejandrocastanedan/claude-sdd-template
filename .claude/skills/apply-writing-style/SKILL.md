# apply-writing-style — Redactar según las reglas del proyecto

## Objetivo
Que todo texto entregable suene como el proyecto/persona quiere, y no a texto genérico de IA.

## Procedimiento
1. **Carga las reglas:** lee `style-guide/writing-style.md`.
2. **Si está vacío o es el placeholder:** ofrece ayudar a crearlo (tono, palabras a evitar, formato); mientras, aplica mínimos sanos (claro, directo, sin relleno).
3. **Redacta** el entregable.
4. **Audita antes de entregar:** compara el texto contra cada regla (palabras/patrones prohibidos, tono, formato) y corrige lo que falle.
5. Entrega **solo** lo que pasa la auditoría.

## Principios
- **Auditar es obligatorio** antes de entregar, no opcional.
- Si el texto es correcto pero genérico ("lo pudo escribir cualquiera"), no pasa.
- **Corrige**, no solo señales.
